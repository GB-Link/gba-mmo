Word gap: pause after each 32-bit word so the GBA's serial handler keeps up. Raise it if the stats line shows junk words (1000µs matches the original Raspberry Pi client). Idle polling drains button presses between server ticks for snappier input. Changes apply on the next Start.

Forget Token?

This removes the token from this browser only. The account stays on the server, but without its token it cannot be recovered — if you might want this character back, use Copy Token first.

Replace This Character?

This browser already has a character on this server. Creating a new account (or saving a different token) replaces the saved token — if the current one isn't copied somewhere safe, that character becomes unrecoverable. Use Copy Token first to keep it.
